# 社内AI勉強会 告知ページ

社内AI勉強会「AIと、はたらく。」の告知ページです。

## ブラウザでプレビューする

プレビューサーバーを起動した状態で、次のリンクをクリックしてください。

### [▶ 完成したWebページを開く](http://localhost:4173)

Python 3を用意し、リポジトリのルートで次のコマンドを実行してください。パッケージのインストールは不要です。

```bash
python3 -m http.server 4173
```

ブラウザで <http://localhost:4173> を開くと、完成したページを確認できます。終了するときはターミナルで `Ctrl+C` を押してください。

外部端末から確認する場合は、次のコマンドでネットワーク上に公開できます。

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Node.jsが利用できる環境では、`npm run dev` または `npm run preview` でも同じプレビューサーバーを起動できます。いずれもコンテナやリモート開発環境のポート転送からアクセスできるよう、すべてのネットワークインターフェースで待ち受けます。
